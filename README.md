# My CLI Tool

A powerful CLI tool for everyday tasks.

## Features

- 🚀 Fast and lightweight
- 🎨 Beautiful terminal output
- 📦 Easy to install and use
- 🔧 Highly customizable

## Installation

```bash
# Install globally
npm install -g my-cli-tool

# Or use npx
npx my-cli-tool
```

## Usage

```bash
# Show help
my-cli-tool --help

# Say hello
my-cli-tool hello

# Show version
my-cli-tool --version
```

## Development

```bash
# Clone the repository
git clone https://github.com/your-username/my-cli-tool.git
cd my-cli-tool

# Install dependencies
npm install

# Run in development
npm start
```
