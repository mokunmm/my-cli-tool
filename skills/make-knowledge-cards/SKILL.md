# Make Knowledge Cards

将文章或本地 Markdown/TXT 文件智能转换为结构化知识卡片。

## 核心能力

- 从用户粘贴的文章内容中提取关键知识点
- 读取本地 `.md` 或 `.txt` 文件并生成知识卡片
- 每张卡片聚焦一个核心知识点
- 输出格式统一、简洁、易于复习

## 使用方式

### 输入方式

1. **粘贴文章**：用户直接在对话中粘贴文章内容
2. **文件路径**：用户提供本地 Markdown 或 TXT 文件路径

### 处理流程

1. 获取输入内容（粘贴文本或读取文件）
2. 分析文章结构，识别核心知识点
3. 按照卡片模板生成 5~8 张知识卡片
4. 输出到指定位置或直接展示

## 卡片模板

每张知识卡片包含以下字段：

```
### 卡片 N：[标题]

**核心知识**：一句话概括这个知识点的本质

**简明解释**：2-3 句话清晰解释这个概念

**例子/自测问题**：
- 例子：[具体示例]
- 自测：[检验理解的问题]
```

## 提取原则

1. **真实性**：只提取原文中明确存在的信息，绝不编造
2. **独立性**：一张卡片只讲一个知识点，避免信息混杂
3. **去重性**：删除重复内容，合并相似概念
4. **适量性**：信息不足时不要强行凑数，宁可少不要滥
5. **重要性**：优先提取核心概念、关键结论、实用方法

## 输出格式

输出为 Markdown 格式，结构如下：

```markdown
# 📚 知识卡片：[文章标题/主题]

> 共 N 张卡片 | 来源：[文件名或"用户粘贴"]

---

### 卡片 1：[标题]

**核心知识**：[一句话概括]

**简明解释**：
[2-3 句解释]

**例子/自测问题**：
- 例子：[示例]
- 自测：[问题]

---
（重复以上结构）
```

## 限制说明

- 不支持网页抓取（需要用户提供文本内容）
- 不支持 PDF 文件解析
- 不支持导出为 Anki 格式
- 不提供图形界面

## 质量检查

生成卡片后，自查以下几点：

1. 每张卡片是否只包含一个核心知识点？
2. 解释是否简洁清晰，不超过 3 句话？
3. 是否有编造原文不存在的信息？
4. 卡片数量是否合理（5-8 张）？
5. 例子或自测问题是否与知识点直接相关？
